# 道诡异仙：诳语双界

> 改编自狐尾的笔《道诡异仙》的免费同人互动叙事游戏。非官方作品，原作版权归作者所有。

## 怎么玩

直接双击 `index.html`，或在浏览器打开它。

- 点击场景里的行动推进这一夜；每个行动会花掉“时辰”，也可能让人起疑。
- 点“闭上眼 / 睁眼”在两个世界之间往返。每次回到这边，道韵 +1。
- 怀里的东西跨界会**变形**：糖变铁锈钉、玉佩变灰石头、荧石变镜片、黑太岁肉变黑药丸。
- 对 NPC 说**诳语**：选一句主张，可以再出示一件证据。信不信取决于他知道什么、你之前说过什么、你身上“不对劲”的程度。
- 说出去的话会被记住；下一幕有人会拿它来问你。
- 道韵满 10、被识破 3 次、骗不过丹阳子，都会失败，可以重来。

建议桌面浏览器 1280×720 以上。有 4 个主要结局和若干失败结局。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `daogui-kuangyu`）。
2. 把本文件夹里的 **全部文件**（`index.html`、`style.css`、`art.js`、`content.js`、`engine.js`、`.nojekyll`）上传到仓库根目录。
3. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`。

说明：
- 全部是静态文件，不需要构建、不需要后端、不加载任何外部资源。
- 所有路径都是相对路径，放在仓库根目录或子目录都能跑。
- `.nojekyll` 是空文件，用来避免 GitHub Pages 的 Jekyll 处理；保留它即可。

## 技术

- 原生 HTML + CSS + 原生 JavaScript（ES2020），零依赖、零构建。
- 场景画面为内联 SVG（`art.js` 生成 data URI），纸纹与配色由 CSS 完成。
- 存档使用浏览器 `localStorage`，不上传任何数据。
